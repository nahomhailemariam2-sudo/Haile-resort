# HAILE — Modern African Luxury Concept

A premium, cinematic front-end concept for Haile Resort Hawassa / Haile Hotels & Resorts.

## Files

- `index.html` — complete page structure and content
- `style.css` — responsive luxury/editorial design system
- `script.js` — scroll reveals, mobile menu, cursor, parallax, lightbox and interactions

## Image handling

The demo references image URLs served by Haile Hotels & Resorts' official website. If you have written permission to use the images commercially, you can keep these URLs or download the approved originals into a local `assets/` folder and replace the `src` values.
